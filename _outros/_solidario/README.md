# Fundo Solidário

> **Pasta:** `_outros/_solidario`

> **Categoria:** Site estático informativo de iniciativa solidária, com conteúdo sobre doações, notícias e centros de acolhimento; contém também um subsite separado de conteúdo educativo sobre informática.
