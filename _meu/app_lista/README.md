# Quadro Kanban

> **Pasta:** `_meu/app_lista`

> **Categoria:** Aplicação web estática de quadro Kanban

## Finalidade

O HTML apresenta cinco colunas de estado, cartões de tarefas com prioridade, ícones de comentários/anexos e avatares. O JavaScript implementa arrastar e largar cartões entre colunas. Os cartões são conteúdo de exemplo; não há no código consultado lógica de armazenamento persistente. Os botões de adicionar cartão estão presentes, mas não têm comportamento ligado no JavaScript analisado.

## Tecnologias observadas

- HTML
- CSS
- JavaScript sem framework
- Google Fonts (Poppins, via CSS remoto)
- Font Awesome 6.6 (CDN externo)
