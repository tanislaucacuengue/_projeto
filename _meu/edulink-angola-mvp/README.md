# EduLink Angola MVP

> **Pasta:** `_meu/edulink-angola-mvp`

> **Categoria:** Aplicação web estática EduLink Angola para ligar alunos a professores particulares

## Finalidade

O HTML e JavaScript próprios descrevem e implementam uma interface para pesquisar professores por disciplina/localidade, registar e autenticar utilizadores, gerir perfis de aluno/professor e agendar aulas. A persistência e autenticação observadas são inteiramente no navegador via localStorage; não foi identificado backend no projecto.

## Tecnologias observadas

- HTML5
- CSS próprio (sem framework identificado)
- JavaScript no navegador, sem framework ou dependências de pacote identificados
- localStorage para sessão e dados
- Google Fonts remoto (Montserrat e Open Sans)
