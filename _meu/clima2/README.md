# Clima 2

> **Pasta:** `_meu/clima2`

> **Categoria:** Aplicação web estática de meteorologia

## Finalidade

A interface permite pesquisar uma cidade e consultar dados de tempo actuais; o código também procura dados de qualidade do ar e poluentes. Esta finalidade é confirmada pelo texto da interface e pelas chamadas presentes nas fontes. A árvore examinada está na branch predefinida principal.

## Tecnologias observadas

- HTML5
- CSS
- JavaScript sem framework aparente
- OpenWeatherMap Weather API e Air Pollution API
- Font Awesome via CDN
- Google Fonts (Poppins) via CSS import
