# Gerador de Cores RGB

> **Pasta:** `_meu/_gerador_Cor_RGB`

> **Categoria:** Aplicação web estática — gerador de cores RGB

## Finalidade

O único ficheiro do projecto apresenta três controlos deslizantes RGB (intervalo 0–255) e actualiza, ao mover qualquer controlo e ao carregar a página, a cor de fundo do documento e um campo de resultado só de leitura com a representação CSS rgb().
