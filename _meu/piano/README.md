# Piano Virtual

> **Pasta:** `_meu/piano`

> **Categoria:** Aplicação web estática de piano virtual

## Finalidade

Pela estrutura HTML e pelo JavaScript, é uma interface de piano com teclas clicáveis e mapeamento para teclado do computador, usando ficheiros WAV locais por nota. A página inclui um interruptor para mostrar rótulos de teclas.

## Tecnologias observadas

- HTML
- CSS
- JavaScript nativo (DOM e Audio do navegador)
- Áudio WAV local em _meu/piano/notas/

## Ficheiros de entrada
