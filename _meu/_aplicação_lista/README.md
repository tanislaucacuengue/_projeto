# Lista de Tarefas

> **Pasta:** `_meu/_aplicação_lista`

> **Categoria:** Aplicação web estática de lista de tarefas

## Finalidade

O único ficheiro de aplicação, index.html, apresenta um campo para inserir tarefas, acrescenta tarefas ao carregar Enter, permite alternar um estado concluído e remover tarefas. Os dados existem apenas na página enquanto está aberta; não há persistência demonstrada no código consultado.

## Tecnologias observadas

- HTML estático
- CSS inline
- JavaScript inline
- jQuery 3.7.1 via CDN
- Font Awesome 6.5.1 via CDN
