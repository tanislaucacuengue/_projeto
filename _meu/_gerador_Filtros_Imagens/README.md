# Gerador de Filtros de Imagem

> **Pasta:** `_meu/_gerador_Filtros_Imagens`

> **Categoria:** Ferramenta web estática de pré-visualização de filtros CSS em imagem

## Finalidade

Com base em index.html: oferece controlos deslizantes para grayscale, sepia, blur, invert, opacity, brightness, contrast e saturate; ao alterar um controlo, aplica os valores como filtros CSS à imagem e apresenta o texto do filtro. Verificado na branch predefinida principal.

## Tecnologias observadas

- HTML5
- CSS
- JavaScript inline
- jQuery 3.5.1 carregado de CDN externa
