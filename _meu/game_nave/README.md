# Game Invasão

> **Pasta:** `_meu/game_nave`

> **Categoria:** Jogo web estático de nave em canvas (protótipo/implementação parcial)

## Finalidade

O HTML chama-o 'Game Invasão'; as fontes implementam um canvas 2D e uma nave/jogador que se move horizontalmente com A/D. Há recursos com nomes de invasores, tiros e efeitos, mas o ciclo de jogo inspecionado apenas move e desenha o jogador; não encontrei lógica de disparo ou inimigos nessas fontes.

## Tecnologias observadas

- HTML5
- CSS
- JavaScript sem framework, com módulos ES
- Canvas 2D
- Recursos locais PNG e MP3
