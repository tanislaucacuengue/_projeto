# Contador e Simulação de Chuva

> **Pasta:** `_meu/contador`

> **Categoria:** Contagem regressiva com resultado aleatório de sim/não apresentado como previsão de chuva

## Finalidade

O código contém três páginas HTML relacionadas com contagens regressivas de 60 minutos. A página da raiz apresenta uma mensagem aleatória SIM/NÃO associada à chuva; as variantes contagem e tempo também geram respostas aleatórias. A lógica observada usa Math.random() e não consulta dados meteorológicos; portanto, o código sustenta a descrição de simulação, não de previsão meteorológica real.
