# Quiz de Conhecimentos Gerais

> **Pasta:** `_meu/_jogo`

> **Categoria:** Jogo web estático / quiz de conhecimentos gerais

## Finalidade

Pelo conteúdo dos HTML e JavaScript, é um quiz de conhecimentos gerais com perguntas de escolha múltipla, feedback visual de resposta certa/errada e pontuação. Há duas variantes: index.html com quatro perguntas e index (2).html com dois níveis de quatro perguntas cada; cada HTML aponta para os seus próprios ficheiros CSS e JavaScript correspondentes.
