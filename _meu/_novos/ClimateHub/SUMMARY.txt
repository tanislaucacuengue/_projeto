1. DESCRIÇÃO GERAL
================================================================================

ClimateHub é uma plataforma web educativa e interativa que integra:
- Informações detalhadas sobre alterações climáticas
- Impactos globais e locais
- Soluções práticas e ações
- Aplicação de previsão do tempo em tempo real
- Monitoramento de qualidade do ar

Desenvolvida em HTML5, CSS3 e JavaScript vanilla, sem dependências externas.

8. COMO USAR
================================================================================

OPÇÃO 1: ABRIR LOCALMENTE
1. Descarregue os ficheiros
2. Abra index.html num navegador

OPÇÃO 2: SERVIDOR LOCAL (Python)
1. Abra terminal na pasta do projeto
2. Execute: python3 -m http.server 8000
3. Aceda a: http://localhost:8000

OPÇÃO 3: SERVIDOR LOCAL (Node.js)
1. Abra terminal na pasta do projeto
2. Execute: npx http-server
3. Aceda a: http://localhost:8080

OPÇÃO 4: LIVE SERVER (VS Code)
1. Instale extensão "Live Server"
2. Clique direito em index.html
3. Selecione "Open with Live Server"

14. SUPORTE
================================================================================

PROBLEMAS COMUNS:

1. App do clima não funciona
   → Verifique conexão à internet
   → Verifique se a API está disponível
   → Tente outro navegador

2. Página não carrega corretamente
   → Limpe cache do navegador
   → Tente em modo incógnito
   → Verifique compatibilidade do navegador

3. Estilos não aparecem
   → Verifique se styles.css está no mesmo diretório
   → Recarregue a página (Ctrl+Shift+R)
   → Verifique console para erros

4. JavaScript não funciona
   → Verifique se script.js está no mesmo diretório
   → Verifique console para erros
   → Ative JavaScript no navegador
