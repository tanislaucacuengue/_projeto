## Funções JavaScript

### Navegação

#### `navegarPara(idPagina)`
Gerencia a navegação entre as diferentes seções da aplicação.

**Parâmetros:**
- `idPagina` (string): ID da página para a qual navegar

**Ações:**
1. Esconde todas as páginas
2. Mostra a página selecionada
3. Atualiza os indicadores de navegação
4. Rola a página para o topo
5. Inicializa a app do clima se necessário

**Exemplo de uso:**
```javascript
navegarPara('aplicacao-clima');
```

### App do Clima

#### `inicializarAppClima()`
Configura os eventos necessários para que a app do clima funcione.

**Ações:**
1. Obtém o formulário de pesquisa
2. Adiciona listener para o evento de envio
3. Marca a app como inicializada

#### `manipularPesquisaClima(evento)`
Manipula a pesquisa de clima quando o utilizador submete o formulário.

**Parâmetros:**
- `evento` (Event): Evento do formulário

**Ações:**
1. Previne o comportamento padrão
2. Obtém o nome da cidade
3. Valida a entrada
4. Faz requisições às APIs
5. Atualiza a interface

**Exemplo de uso:**
```javascript
formularioPesquisa.addEventListener('submit', manipularPesquisaClima);
```

### Qualidade do Ar

#### `exibirQualidadeAr(indiceQualidadeAr, descricao)`
Exibe a qualidade do ar na interface.

**Parâmetros:**
- `indiceQualidadeAr` (number): Índice de qualidade (1-5)
- `descricao` (string): Descrição textual

**Ações:**
1. Obtém o elemento do cartão
2. Mostra o cartão
3. Atualiza o valor e descrição

#### `esconderQualidadeAr()`
Esconde o cartão de qualidade do ar.

**Ações:**
1. Obtém o elemento do cartão
2. Esconde o cartão

#### `obterDescricaoQualidadeAr(indiceQualidadeAr)`
Converte o índice numérico em descrição textual.

**Parâmetros:**
- `indiceQualidadeAr` (number): Índice de qualidade (1-5)

**Retorna:**
- (string): Descrição textual

**Mapeamento:**
- 1 → "Boa"
- 2 → "Moderada"
- 3 → "Má"
- 4 → "Muito Má"
- 5 → "Péssima"

### Poluição do Ar

#### `exibirPoluicaoAr(componentesPoluentes)`
Calcula e exibe o índice de poluição do ar.

**Parâmetros:**
- `componentesPoluentes` (object): Componentes poluentes

**Propriedades do objeto:**
- `pm2_5`: Partículas finas
- `pm10`: Partículas grosseiras
- `no2`: Dióxido de nitrogénio
- `o3`: Ozono

**Ações:**
1. Obtém o elemento do cartão
2. Mostra o cartão
3. Calcula a média dos componentes
4. Atualiza o valor

#### `esconderPoluicaoAr()`
Esconde o cartão de poluição do ar.

**Ações:**
1. Obtém o elemento do cartão
2. Esconde o cartão

### Exibição de Informações

#### `exibirInformacoesClima(dadosClima)`
Atualiza todos os elementos com as informações do clima.

**Parâmetros:**
- `dadosClima` (object): Dados do clima

**Propriedades do objeto:**
- `cidade`: Nome da cidade
- `pais`: Código do país
- `temperatura`: Temperatura atual
- `temperaturaMaxima`: Temperatura máxima
- `temperaturaMinima`: Temperatura mínima
- `descricao`: Descrição do clima
- `iconeClima`: Código do ícone
- `velocidadeVento`: Velocidade do vento
- `umidade`: Percentagem de umidade

**Ações:**
1. Mostra a seção do clima
2. Atualiza o título
3. Atualiza a temperatura
4. Atualiza o ícone
5. Atualiza as outras informações

#### `exibirAlerta(mensagem)`
Exibe mensagens de alerta na interface.

**Parâmetros:**
- `mensagem` (string): Mensagem a exibir

**Ações:**
1. Obtém o elemento da área de alerta
2. Atualiza o conteúdo HTML
