# ClimateHub

> **Pasta:** `_meu/_ClimateHub`

> **Categoria:** Website educativo estático com aplicação interactiva de meteorologia e qualidade do ar

## Finalidade

ClimaHub/PlataformaClima apresenta-se como plataforma educativa sobre alterações climáticas, com secções informativas e pesquisa de condições meteorológicas e qualidade do ar. O JavaScript consulta a API OpenWeatherMap para obter dados meteorológicos.

## Tecnologias observadas

- HTML5
- CSS3
- JavaScript vanilla (ES6+), sem framework aparente
- Font Awesome via CDN (HTML referencia 6.5.1; documentação declara 7.0.1)
- Google Fonts: Poppins
- OpenWeatherMap API v2.5 (tempo actual e qualidade do ar)
- Frontend estático; não foi encontrado manifesto de dependências/build no diretório do projecto
