# Jogo da Memória

> **Pasta:** `_meu/game_memoria`

> **Categoria:** Jogo da memória para navegador implementado como aplicação web estática.

## Finalidade

A página inicial solicita um nome de jogador e encaminha para uma grelha de cartas com pares, contagem de tempo e verificação de vitória. Esta finalidade é evidenciada pelo HTML e JavaScript próprios; não executei a aplicação.

## Tecnologias observadas

- HTML
- CSS
- JavaScript sem framework (DOM e APIs do navegador)
- Web Storage localStorage para o nome de jogador
- Bootstrap referenciado por caminho relativo a node_modules (dependência vendorizada não inspecionada)
