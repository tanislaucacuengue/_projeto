# Gerador de Senhas

> **Pasta:** `_meu/_gerador_senhas`

> **Categoria:** Aplicação web estática — gerador de palavras-passe

## Finalidade

HTML apresenta uma interface para escolher comprimento e tipos de caracteres, gerar uma palavra-passe e copiá-la para a área de transferência. Essa finalidade é comprovada pelos controlos em index.html e pelo comportamento implementado em src/js/script.js.

## Tecnologias observadas

- HTML
- CSS
- JavaScript sem framework aparente
- Toastify JS e Font Awesome via CDN
- Roboto Mono via Google Fonts
