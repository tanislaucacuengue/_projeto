# Game Cobra

> **Pasta:** `_meu/game_cobra`

> **Categoria:** Jogo Snake/Cobra para navegador

## Finalidade

A página HTML e o JavaScript implementam um jogo de cobra em canvas: movimentação por teclas de seta, pontuação, recorde local, pausa com Enter, reinício, controlo de velocidade, colisão com limites/auto-colisão e áudio ao comer. Esta finalidade é confirmada pelo código, não por inferência externa.

## Tecnologias observadas

- HTML5
- CSS
- JavaScript sem framework evidente
- Canvas 2D
- APIs do navegador: localStorage e Audio
- Bootstrap 5.3.8 declarado como dependência e referenciado no HTML; não há uso de APIs Bootstrap evidente na lógica própria examinada
