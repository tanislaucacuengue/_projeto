# Game Mario

> **Pasta:** `_meu/game_mario`

> **Categoria:** Jogo web estático de obstáculos inspirado em Mario, controlado por teclado.

## Finalidade

O HTML apresenta Mario, nuvens e um cano; o JavaScript permite saltar, pausar/retomar com Enter, acelera o cano ao longo do tempo e pára a animação ao detectar colisão. A finalidade decorre dos ficheiros de código; não foi inferida apenas do nome.

## Tecnologias observadas

- HTML estático
- CSS (animações com keyframes)
- JavaScript sem framework (DOM, eventos de teclado e temporizadores)
- Imagens locais GIF/PNG/JPEG
