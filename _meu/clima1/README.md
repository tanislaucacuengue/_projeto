# Clima 1

> **Pasta:** `_meu/clima1`

> **Categoria:** Aplicação web estática de consulta meteorológica

## Finalidade

A interface permite pesquisar uma cidade e exibe dados meteorológicos actuais — temperatura, máximas/mínimas, descrição, humidade e vento — além de qualidade do ar e valores de poluentes quando disponíveis. Isto é evidenciado pelo HTML e pelas chamadas da API de clima e poluição no JavaScript; não há evidência de previsão para vários dias.

## Tecnologias observadas

- HTML
- CSS
- JavaScript sem framework
- API OpenWeatherMap (clima actual e poluição do ar)
- Font Awesome por CDN
- Google Fonts (Poppins) por CSS externo
